```
│
├── security-plus/                 # CompTIA Security+ notes by domain
│
├── cheatsheets/                   # quick command/tool references
│   ├── grep.md
│   ├── dirb.md
│   └── linux-basics.md
│
└── concepts/                      # cross-course fundamentals
    ├── cia-triad.md
    └── ...
```

- **By course → by module** keeps each course's material self-contained and easy to review before an exam.
- **Cheatsheets** are tool/command references you'll reuse constantly (start with the `grep` and `dirb` notes).
- **Concepts** is for fundamentals that span multiple courses (CIA triad, risk, frameworks) — one clean file you can link back to instead of re-explaining.

## Note Format

Each note is a markdown file. A simple, repeatable shape keeps them useful:

- **Topic** — what this note covers
- **Key points** — the core ideas in your own words
- **Terms** — any new vocabulary + plain-English definition
- **Why it matters** — where this shows up in a real security role

Written in your own words beats copied slides every time — it's what makes the notes stick *and* what makes them worth showing.
